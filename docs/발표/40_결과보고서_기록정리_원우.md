## 1. 서비스 개요·문제 정의 🔶
- 기획서 「기획 배경」 그대로: 고효과 교육활동(국제교류·현장실습·비교과)의 경험 정보가 흩어져 있고, 관리 부서는 학생이 무엇을 모르는지 알기 어렵다.
- 이수 규모: 국제교류 1,185 · 현장실습 295 · 비교과 8,067명(대학정보공시·HUFSAbility, PRD 1-1).
- ⬜ 수요 설문 수치(56, 11/29 마감 — 11/23 14명) — `tools/survey_summary.py`의 「파급효과 슬라이드용 한 줄」을 넣는다.

## 2. 시스템 구성도 ⬜
- 그릴 것(통합 배포 뒤 실제 구조로): 화면(GitHub Pages, `screens/`) → `common/data.js`(mock/서버 전환) → NCP Cloud Functions(`functions/`) → 쓰기 저장소(`runtime/*.json`) + 사전 생성 데이터(`data/*.json`) → `callAI`(마스킹·사용자별 한도·기록) → HCX / Claude(PROVIDER).
- askBoo 흐름(확정): ①프로그램 대조(별칭·인턴 사전·나라 이름) → ①′규정 질문 → 공식 안내 → ②근거 추출(칸 주제어) → ③AI 번호 고르기 → ④AI 말투 변환(이미 존댓말이면 생략) → ⑤코드 사후 검증 → 출처 블록.
