## 슬라이드 A. 「질문 1건에 ＿원」 — 운영비

**한 줄 메시지(안)**: 질문 하나에 ＿원, 재학생이 한 학기 내내 써도 연 ＿만 원 수준입니다.

### A-1. 질문 1건이 부르는 AI (PROVIDER 표, 11/25 main)

| 순서 | 단계 | 모델 | 비고 |
|---|---|---|---|
| ① | 질문 정리 | Sonnet | 최근 대화 4턴 + 질문 → 의도·프로그램·칸 |
| ④ | 근거 고르기 | **HCX(CLOVA)** | 번호만 고름 |
| ⑤ | 답 쓰기 | Sonnet | 문장마다 근거 번호 |
| ⑥ | 답 검사 | Opus | 답 문장 ↔ 근거 원문 대조 |
| — | 보류·공식안내·대화 | 일부 단계 생략 | 대화는 질문 정리(①) 뒤 고정 문구(답 쓰기·검사 없음). 보류는 고르기 전에 멈출 때도, 답 쓰기 뒤에 멈출 때도 있어(`askboo.py` 「답쓰기 근거 없음」) 유형별 원가는 88 기록으로 따로 잰다 |

- 인터뷰(들려주기)는 질문이 아니라 **선배 1명당 1회**라 따로 센다: 충분판정·꼬리질문(HCX) + 요약(Sonnet) + 일치검사(Opus).
- 닮은선배·점수·집계·콘솔 수치는 **AI 없음**(비용 0).

### A-2. 계산 (11/29 88 측정 기록으로 채움)

| 항목 | 값 | 어디서 |
|---|---|---|
| 질문 1건 평균 토큰(입력/출력) | ＿ / ＿ | 88 측정의 `ai-calls.jsonl` (미리 PC, 같은 커밋) |
| 질문 1건 Claude 원가 | ＿원 | 위 토큰 × Sonnet·Opus 단가(운영노트 4절), 환율 ＿원 |
| 질문 1건 HCX 원가 | ＿원 | NCP 이용 요금(크레딧 차감액) ÷ 호출 수 — 단가 공개 안 됨, 콘솔 실측 |
| **질문 1건 합계** | **＿원** | |
| 인터뷰 1회 원가 | ＿원 | 들려주기 3답 기준 |

### A-3. 연간 추정 (가정은 슬라이드에 그대로 적는다)

| 가정 | 값 | 근거 |
|---|---|---|
| 대상 학생 | ＿명 | 미리 결정: 재학생 전체 또는 이수 경험 대상(국제교류 1,185 · 현장실습 295 · 비교과 8,067명, PRD 1-1) |
| 한 학기에 써 보는 학생 비율 | ＿% | 설문 「비슷한 선배 추천 받고 싶다」 92%(응답자 61명 기준)는 의향이라 그대로 쓰지 않는다. 보수적으로 ＿% |
| 1인당 학기 질문 수 | ＿개 | 시드 사용 로그(1,200질문) 또는 가정 |
| 인터뷰 수 | ＿회/학기 | 귀국보고서·실습 종료 시점 연결(아래 C) |
| **연 운영비** | **＿만 원** | (질문 수 × 질문 원가 + 인터뷰 수 × 인터뷰 원가) × 2학기 + 서버 ＿만 원 |

- 서버: Cloud Functions·Object Storage는 호출·용량 과금이고 NAT Gateway는 시간 과금(운영노트 4절) — 운영 시 학교 서버에 올리면 ＿.
- 안전장치(지금 코드): 사용자별 분당 10·일 100, 전역 일 2,000건 상한(`functions/limits.py`), NCP Budgets 알림 50%·80%.
- **말하지 않을 것**: 단가를 모르는 HCX를 추정치로 채우지 않는다. 실측이 없으면 「Claude 원가 ＿원 + HCX는 크레딧 차감 실측 ＿원」처럼 나눠 쓴다.

## 슬라이드 B. 누가 운영하나 — 운영 주체와 부서에 돌아오는 것

## 슬라이드 C. 로드맵 — 이번에 뺀 것의 행선지

**한 줄 메시지(안)**: 이번에 뺀 것은 버린 것이 아니라 운영 단계로 옮긴 것입니다.

| 단계 | 넣을 것 | 왜 이번엔 뺐나 / 조건 |
|---|---|---|
| **도입기(첫 학기) = 동의 수집기** | 귀국보고서 제출·현장실습 종료 시점에 5분 인터뷰 연결(항목당 질문 1~2개), 보고서·후기 제출 양식에 공개 동의 칸 | 이것 없이는 출시 날 근거가 0 (PRD 4-3 운영 전환 조건). 설문: 경험자 중 3분 인터뷰 의향 74%(35/47) |
| 도입기 | 현장실습지원센터 후기 연동(동의 조건 동일), 실제 질문 로그(학번 제거)로 콘솔 시드 교체 | 대회는 가상 데이터만 |
| 도입기 | 학교 SSO 로그인, 리포트 **실제 메일 발송** | 대회는 비번 표·미리보기만(작업 43 P2) |
| 도입기 | 보관기간 자동 삭제 스케줄러 | 규칙은 있음(PRD 9-3), 실행은 트리거로 |
| 확장기 | **임베딩 검색**(질문 정리 + 후보 추출) — 지금의 주제어·별칭·인턴 사전을 대체 | 측정 직전에 근거 찾는 방식을 바꾸면 다시 재야 해서 뺌(58③, 11/29 결정) |
| 확장기 | CLOVA Studio 라우터(가드레일)로 쪽지 비방 판정 | 측정 통과가 전제(76, 11/29 결정) |
| 확장기 | 내 경험노트 → 자소서용 요약 | 자유 생성 위험이 가장 큰 호출, 시연 밖(PRD 2-2) |
| 확장기 | 「후배가 ○○ 경험을 기다려요」 선배 알림, 예시답 칩·음성 입력 | PRD 4-2 ⑨, 11장 |
| 확장기 | 유학생·다국어 | 범위 밖(국내 재학생·한국어). MY HUFS 번역 레이어로 |

- 11/29 중간 점검 결과에 따라 행이 바뀐다: 58③·76을 이번에 넣으면 그 행을 지운다(지금 원우 의견은 둘 다 로드맵, 1129 점검재료 2-5).

## 방어 자료 답 문안 (Q6·Q7에 그대로)

- **Q6 「대회 끝나면 누가 운영하나요?」** MY HUFS 학생용 모듈로 올립니다. 화면은 그대로 두고 서버 주소·로그인·저장소만 바꾸면 되도록 만들었습니다(운영노트 7절). 운영은 ＿이 총괄하고, 데이터는 원래 주인인 각 프로그램 운영 부서가 갖습니다. 부서는 따로 검토하지 않아도 되고, 관리자 콘솔로 학생 수요와 개선 제안을 받아 봅니다.
- **Q7 「운영비는요?」** 질문 하나에 ＿원입니다(11/29 측정, 같은 코드로 90문항). 재학생 ＿명 중 ＿%가 한 학기 ＿번 묻는다고 잡으면 연 ＿만 원입니다. 사용자별·전체 하루 상한과 예산 알림이 코드와 콘솔에 걸려 있습니다.
