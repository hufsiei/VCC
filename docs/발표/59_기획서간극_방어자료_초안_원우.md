## 2. 기획서대로 지킨 것 (바뀐 것만 말하면 약해 보인다)

- 근거가 없으면 지어내지 않고 질문함 → 선배 인터뷰 주제(기획서 「돌발 질문」 대응 그대로) — **질문 → 인터뷰 → 노트 → 알림** 순환이 시연에서 돈다
- 들려주기: 노트의 근거가 적은 칸을 먼저 질문 — 더 나아가 **보고서가 이미 답한 칸은 묻지 않음**(11/22)
- 닮은 선배: 관심 경험으로 후보 → 전공·단과대·비교과로 순위, **초기 미션 뒤 추천 열림**(기획서 문구 그대로 구현, 11/22 「선배 추천 열림」)
- 익명 쪽지: 수락 뒤 1:1, 신고·차단, 학번·이름 비공개
- 가상 데이터만, 실제 명단·원문을 AI에 넣지 않음 + AI로 나가는 글은 **마스킹 후 전송**(시험 12,424건 틀림 0)
- AI 키는 서버 함수에만(점검표 9장)
- 데이터: 종합정보시스템·HUFSAbility 헤더 구성 그대로 가상 1,000명 + 귀국보고서 280편·현장실습 후기 1,438문장 → 근거 4,798개

## 3. 예상 질문과 답 (20개)

> 답은 30초 안. 숫자는 측정 조건과 함께 말한다. **[＿]**는 측정 뒤 채운다.

### 완성도·실현가능성 (30)
1. **「RAG라고 했는데 벡터 검색이 없네요?」**
   11/14·16에 자유 생성으로 시험했더니 근거에 없는 시험 점수·조언을 지어냈습니다. 그래서 프로그램명 글자 대조로 근거를 꺼내고, AI는 번호를 고르고 말투만 바꾸게 했습니다. 질문한 프로그램의 근거만 꺼내 번호를 붙이므로 AI는 번호만 고르면 되고, 개발 질문 70개에서 근거 없는 답 0건입니다.
2. **「근거 없는 답 0건은 어떻게 잰 건가요? 직접 만든 질문 아닌가요?」**
   질문은 개발용 70개와 **봉인 30개**로 나눴고, 봉인 30개는 개발 중에 팀이 보지 않았습니다. 동의어·범위 밖·함정·규정 오해 유형을 섞었습니다. 봉인 결과는 [＿]입니다.
3. **「AI가 문장을 바꾸다 틀리면요?」**
   바꾼 문장에 원문에 없는 숫자·영문·고유명사·새 낱말이 있으면 코드가 버리고 원문을 그대로 보여 줍니다(사후 검증). AI를 믿지 않는 마지막 관문이 코드에 있습니다.
4. **「업체 이름 없이 '무역 쪽 인턴'이라고 물으면요?」**
   직군·기관유형 사전으로 후보 업체 1~3곳을 고릅니다. 직군 질문 14개 모두 맞는 업체로 갔고, 「교환 가서 여행」처럼 인턴과 관계없는 질문 30개는 하나도 걸리지 않았습니다. 사전에도 없으면 보류합니다.
5. **「실제 데이터로도 되나요?」**
   종합정보시스템·HUFSAbility 엑셀의 열 이름 그대로 가상 데이터를 만들었습니다. 실제 도입 때는 같은 헤더의 파일을 넣으면 변환 스크립트가 그대로 돕니다(`tools/sheet_to_json.py`).

### 학내 적용·정책화 (30)
6. **「대회 끝나면 누가 운영하나요?」**
   MY HUFS 학생용 모듈로 탑재하고, 데이터 소유는 각 프로그램 운영 부서, 화면은 관리자 콘솔로 부서가 봅니다. [운영 주체·담당 부서는 작업 55 슬라이드와 맞춤]
7. **「운영비는요?」**
   질문 1건당 [＿]원(호출 로그 실측) → 재학생 규모로 연 [＿]원입니다. 이미 존댓말인 근거 문장은 AI를 부르지 않게 하면 호출이 더 줄어듭니다(작업 30 분석).
8. **「부서가 왜 이걸 쓰나요? 일만 늘지 않나요?」**
   부서는 검토·승인을 하지 않습니다. 학생들이 많이 묻는데 답이 없는 칸을 콘솔이 「개선 제안」으로 보여 주고, 정해진 날 리포트가 갑니다. [부서 담당자 의견(작업 64) 인용]
9. **「선배가 왜 인터뷰에 응하나요?」**
   ① 내 경험노트가 자동으로 남고(자소서 소재) ② 공개는 문장 단위로 내가 고르며 ③ 운영 때는 마일리지·오픈배지와 연계합니다. 보고서가 이미 답한 칸은 묻지 않아 5분이면 끝납니다.
10. **「귀국보고서를 쓰는 학생에게 또 인터뷰를 시키면 중복 아닌가요?」**
    보고서는 그대로 근거로 쓰고, 인터뷰는 보고서에 없는 것(오해·후회·비교)만 묻습니다. 로드맵에서는 보고서 제출 시점에 인터뷰를 붙여 일부 항목을 대신할 수 있습니다.

### AI·NCP
14. **「왜 CLOVA만 쓰지 않았나요?」**

### 개인정보·보안
17. **「선배를 특정할 수 있지 않나요?」**
    추천 선배는 「독일어과 선배 A」, 쪽지 보낸 사람은 「용감한 수달」로만 보이고 학번·입학년도는 넣지 않습니다. 해봤노트 배운점의 「선배 A」는 학과를 빼 소수 학과에서도 특정되지 않게 했고, 추천 목록은 한 번에 최대 9명이라 학과 선배 명단을 훑을 수 없습니다.
18. **「AI 회사로 개인정보가 나가지 않나요?」**
    AI로 보내기 직전에 서버가 연락처·메일·학번·URL·상세 주소를 가립니다(시험 12,424건 틀림 0). 기록 파일에도 가린 뒤 값만 남깁니다. 공개 동의하지 않은 보고서는 소급해 쓰지 않습니다.
19. **「쪽지로 연락처를 주고받거나 괴롭히면요?」**
    전화·SNS 아이디는 보내기 전에 막고, 선배당 요청 1건·대기 3건·받는 선배당 5건으로 제한, 7일 지나면 만료, 신고·차단이 있습니다.
