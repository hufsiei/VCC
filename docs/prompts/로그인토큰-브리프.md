새 Claude Code 세션(Sonnet 5.5 · medium)이 이 파일만 읽고 시작한다. 피드백 녹취·PRD 전문은 읽지 않아도 된다.
작성 2026-11-20(미리). 작업내역 v6 작업 73·86, PRD 9-4 점검표 6번, spec 2-1(「누가 부르는지」).

## 시작 프롬프트(붙여넣기)

```
docs/prompts/로그인토큰-브리프.md를 읽고 그대로 구현해 줘. CLAUDE.md 규칙(worktree, 내 폴더만, PR)을 지킨다.
브리프에 없는 결정이 필요하면 먼저 물어보고, 있는 결정은 바꾸지 않는다. 키 값은 .env에 있으니 읽어서 쓰고 대화창에 붙이지 않는다.
```

## 1. 왜 하나(배경 3줄)

- 저장소가 공개(GitHub Pages)라 `data/students.json`(비번 전원 `1`), 함수 이름, API Gateway 주소가 전부 보인다.
- 서버는 헤더 `X-User`만 믿는다. 헤더만 바꾸면 로그인 없이 남의 쪽지·경험노트 함수를 부를 수 있고, 시연 계정 학번을 적으면 호출 한도도 면제된다.
- CORS는 브라우저만 막고 curl은 통과한다. 사용자별 한도만으로는 크레딧을 지킬 수 없다(FDE ③-2).

## 3. 지금 구조(바꿀 지점)

| 파일 | 현재 | 바꿀 것 |
|---|---|---|
| `functions/account.py` | `login(me,{id,pw})`가 `students.json`의 `비번`과 대조 → `{ok,user}` | 비번은 **환경변수 `VCC_LOGIN_PW`**(JSON 문자열 `{"H0143":"...","staff01":"..."}`)에서만 읽는다. students.json의 `비번` 열은 읽지 않는다. 성공 시 토큰 발급, `user`에 `token` 추가. `logout(me,{})` 추가 |
| `functions/local_fn.py` | `me = X-User 헤더`, `NEEDS_NO_LOGIN={"checkMessage","login"}`, `AI_ROUTES`에만 `limits.check(me)` | `me = sessions.resolve(X-Token)`. `X-User`는 읽지 않는다. CORS 허용 헤더를 `Content-Type, X-Token`으로. 순서: 토큰 확인 → 전역 상한 → 사용자별 한도 → 함수 |
| `functions/limits.py` | 사용자별 분당 10·일 100, `EXEMPT` 6계정 | `GLOBAL_PER_DAY = 2000` 추가. **시연 계정도 전역 상한에는 포함**(사용자별 한도만 면제). 기록은 `aiUsage.json`의 `"_global"` 키. 초과 메시지 `"오늘 사용량을 다 썼어요. 내일 다시 시도해 주세요"` |
| `functions/sessions.py`(신규) | — | `issue(me) -> token`(secrets.token_urlsafe(24), 24h), `resolve(token) -> me 또는 ""`, `revoke(token)`. 저장은 `store.load("sessions", {})` / `store.save("sessions")` / `store.lock()` 그대로. 만료 항목은 resolve 때 지운다 |
| `functions/cloud/*.py` | CORS 헤더 `Content-Type, X-User` | `Content-Type, X-Token`. 비번은 함수 **기본 파라미터 `VCC_LOGIN_PW`**로 받는다(CLOVA_KEY와 같은 방식) |
| `common/data.js` | `call()`이 `X-User: me.colreg_no` 헤더, `login()`이 `res.user`를 sessionStorage `me`에 저장, mock은 `pw==="1"` | `X-Token: me.token`만 보낸다. `logout()`은 서버 `logout` 호출 후 sessionStorage 삭제. **mock 모드(USE_MOCK)는 그대로** |
| `.env.example`(없으면 만들기) | — | `VCC_LOGIN_PW={"H0143":"...","H0469":"...","H0241":"...","H0745":"...","staff01":"...","staff02":"..."}` 자리만. 실제 값은 `.env`(커밋 금지)에 미리가 넣는다 |

고정 결정: 토큰은 sessionStorage의 `me` 객체 안 `token` 필드(탭마다 따로 → 두 창 시연 유지). 토큰 만료 24h. 같은 계정 동시 로그인 허용(토큰 여러 개). `checkMessage`·`login`만 토큰 없이 허용.

`data/students.json`의 `비번` 열 삭제는 **원우 담당**(`tools/sheet_to_json.py`, `data/README.md` 30행). 이 세션은 건드리지 않고, 서버가 그 열을 더 이상 읽지 않게만 한다.
