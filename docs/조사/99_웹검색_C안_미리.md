## ③ 판단 재료

1. **응답 시간**: direct 3~7초. askBoo 뒤에 붙여도 60초 한도에 여유. 동적 필터링은 쓰지 않는다.
2. **틀린 답**: 환율만 틀렸다(official 2/2). 순위·기관·보도·학교 공지는 출처가 맞았다. 환율은 웹 검색보다 **한국수출입은행 환율 API를 코드로 읽는 쪽**이 맞다(로드맵, AI 불필요).
3. **출처가 공식인가**: 허용 목록이면 6/9, 막는 목록이면 4/9. 공식 우선을 바라면 허용 목록. 단 크롤러 차단 언론 6곳은 넣을 수 없다.
4. **근거 규칙 적용**: 웹 출처는 API가 글 조각에 직접 붙여 주므로(모델이 번호를 적지 않음) 「출처 없는 문장 버리기」는 그대로 된다. 문제는 숫자 규칙 — 인용 글이 150자까지라 맞는 숫자도 버려지고, 「지난 4일」을 모델이 「11월 4일」로 바꿔 쓴 날짜가 버려진다. 넣으려면 날짜 숫자는 검사에서 빼고 기준일을 `page_age`로 코드가 붙이는 보완이 필요. 「찾지 못했어요」 문장은 출처 없이도 남긴다(지우면 4번처럼 다른 답이 된다).
5. **규정 질문이 새지 않게**: AI 부르기 **전에** 코드가 가른다. 규정 말(학점·졸업·장학·휴학·지원 자격·인정 등)이 있으면 웹으로 보내지 않고 공식 안내 문구. 11·12번 2/2 통과, 바깥 질문 1~9번이 규정으로 잘못 가지 않음 9/9. 시스템 문구에도 「학사 규정은 답하지 않는다」.
6. **실존 인물(특강자)**: ① 코드가 연락처·SNS·가족·연봉·사생활 같은 말이 있으면 막는다(10번 통과). ② 허용 목록 모드면 출처가 학교 공지·언론뿐이라 나오는 건 공개 행사 정보(이름·소속·일시·주제)뿐(9번 official). ③ 막는 목록에 나무위키·SNS. 남은 위험: 이름을 넣은 평판 질문(「○○ 대표 어때요?」)은 말 목록으로 다 못 막는다 → 넣으면 인물 질문은 hufs.ac.kr 출처만 허용하는 별도 목록이 안전.

## 초안 (넣기로 할 때만 쓰는 것)

- **의도 「외부정보」**(askboo 질문정리 프롬프트에 넣을 초안, 이번엔 고치지 않음 — Q-50):
  - 정의: 학교 프로그램 근거(노트·안내문) 밖의 **바뀌는 공개 사실** — 환율·세계 대학 순위·기관/기업 소개·학교 보도·특강 행사.
  - 아님: 학사 규정·지원 자격(→ 공식 안내), 사람 개인 정보(→ 거절), 선배 경험(→ 기존 물어보기).
  - 길: 코드 가르기(규정 → 인물 → 외부) 뒤 `callAI("외부정보")`, 답은 출처 붙은 문장만 + 출처 링크.
- **화면 블록**(민지 결정): 답 아래 「웹에서 찾은 출처」 근거 블록 — 도메인·제목·기준일(`page_age`)·「공식/언론」 표시. AI가 만든 답이므로 근거 블록 색 규칙(6-1)을 따름. 출처 0건이면 틀은 두고 「0건」.
- **서버(이 브랜치에 있음)**: `functions/ai.py` — `PROVIDER`·`SETTINGS`에 「외부정보」, `SETTINGS`에 `web_search`가 있으면 `call_claude_web`(pause_turn 이어 부르기, 글 조각+출처·검색 결과·검색 횟수 반환). 다른 작업은 기존 `call_claude` 그대로. 로그에 「웹검색」(횟수) 칸.
- **남은 일(넣을 때)**: `check_security.py` 4번 허용 칸에 「웹검색」(Q-60 제안), `ai_usage.py` 비용에 검색 $0.01/회 더하기, spec askBoo 응답에 웹 출처 필드.
