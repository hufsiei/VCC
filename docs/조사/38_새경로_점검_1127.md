# 작업 38 — 새 AI 경로 개인정보 점검 (11/27, Q-103)

대상은 오늘 들어온 새 경로 세 가지다. 작업 110 대화형 들려주기(`VCC_TELL_CHAT`, `functions/tell_chat.py`, 기록 `runtime/tellChat.json`), 작업 119 물어보기 대화 응답(`VCC_ASK_CHAT`), #379 쪽지 요청의 기준 프로그램(`runtime_fns._request_program`, `getMessages.program`).
기준은 CLAUDE.md 「올리면 안 되는 것」·「AI 호출 규칙」과 spec 0장이다. 이 점검 중 AI는 부르지 않았다(가짜 callAI만 사용).
대조 기준은 `origin/main` 9852a1b다. **119(Q-95)는 승인만 됐고 아직 시작 전**이라(코드·PR 없음) 설계 기준으로만 봤다. 병합되면 `check_security.py`를 한 번 더 돌린다.

## check_security.py 8번 (새 검사)

가짜 callAI로 새 경로를 끝까지 지나가게 한다. AI는 0건, 요금도 0원이다.
- **AI는 callAI로만**: `functions/` 안에서 `ai.py` 밖이 모델 호출 함수·SDK·CLOVA 주소를 쓰면 실패. 예외는 `cloud/clova_once.py`(1차 점검 C-2, 고정 문구)뿐이다.
- **입구 마스킹**: 진짜 `callAI`에 연락처·메일·학번·URL을 넣고, HCX·Claude 길 모두에서 모델 직전 글에 원문이 남지 않았는지 본다. 로그는 임시 파일에 쓴다.
- **대화형 들려주기**: 플래그를 켜고 두 턴을 돈다. tellChat에 말 원문·연락처가 없는지, 초기화 대상인지, 궁금한 말이 내 질문함에 담기는지(연락처가 든 궁금은 안 담김), 남의 질문함·판정에 안 보이는지, 8일 된 기록이 지워지는지, 플래그를 끄면 0건인지 본다.
- **물어보기 대화**: 인사말이 질문함에 안 담기는지, 응답과 askLog `message`에 대화에 없는 연락처가 없는지 본다.
- **쪽지 program**: 추천에서 받은 노트만 저장되는지(위조 noteId → 없음), `getMessages`에 상대 학번이 0건인지 본다.
- **한도(일반 검사)**: 서버 요청 안에서 `limits.check`보다 먼저 AI를 부르려 하면 실패. 앞으로 AI를 부르는 함수를 `AI_ROUTES`에 안 넣으면 여기서 걸린다.
- **초기화 규칙(일반 검사)**: 점검 중 생긴 기록 이름이 모두 `reset_runtime.HANDLED`·`UNTOUCHED`에 있어야 한다. 새 기록을 만들고 초기화 규칙을 안 넣으면 여기서 걸린다.

고장 시험: `interviewNext`를 `AI_ROUTES`에서 빼고, `tellChat`을 `HANDLED`에서 빼고, 말 원문을 키로 저장하게 바꿔 돌렸다. 세 경우 모두 각 항목이 「실패」로 잡혔다.
