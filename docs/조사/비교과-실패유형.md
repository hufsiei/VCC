# 비교과 질문 실패 유형 계측 (작업 106 · Q-49, 11/26 미리)

국제처 「비교과 답변 엉망」 피드백의 원인을 가르려고, 비교과 구어 질문 27문을 공개 서버(`askBoo`)에 던졌다. 코드는 고치지 않았다. Q-50(물어보기 비교과 수선)의 설계 근거다.

- 방법: 공개 주소, 시연 계정이 아닌 학생 계정 H0500·H0600(질문함 오염 방지)으로 로그인, 질문당 7초 간격으로 1회씩 호출. 응답의 `status`와 `message`를 기록하고, 로컬에서 `match_programs`·`full_evidence`(AI 없음)를 같은 질문에 돌려 원인을 가렸다.
- 비용: Claude 답쓰기 호출 0회(27문 전부 답쓰기 앞에서 끝남), HCX 질문정리 27회 안팎. `/token` 기준 오늘 Anthropic $3.28(이 작업 이전 사용분 포함), 한도 $20 안.
- 부작용: 공개 서버 질문함에 H0500·H0600 이름으로 20건(보류 18 + 공식안내 2, Q-0037~Q-0056)이 담겼다(시연 계정 아님).

## 가장 큰 발견 — 비교과에는 근거 문장이 없다

- `data/evidence.json`의 문서 종류는 귀국보고서·현장실습후기뿐이고, **비교과 프로그램 130개 중 근거 문단이 있는 것은 0개**다(`data/notes.json` 비교과 노트 130개 전부 `evidenceCount` 0, 2개만 동의 통과 인터뷰 문장 3~4건).
- 그래서 비교과의 「해봤노트 경험 질문」은 이름을 정확히 말해도(대조군 26·27) 답이 나올 수 없고, 답쓰기(Sonnet)는 한 번도 불리지 않았다. **지금 비교과의 실패는 AI 문제가 아니라 대조·안내 문구 문제**다.
- 비교과에 있는 데이터는 이수 인원(`completedCount`)·만족도·세부 유형·운영부서뿐이다. 이것으로 코드가 답할 수 있는 질문(23)도 답하지 않는다.

### 같은 카드 2장 문제 (T2·T3·T4, 7건: 9·10·13·14·23·24·25)

질문정리가 분야를 「비교과」로 잡고 `_explore`로 가면, 근거가 있는 비교과 노트(`evidence_count`>0)만 후보가 된다. 그런 노트가 2개(Guardians, 동문 초청 릴레이 특강)뿐이라 **질문과 상관없이 늘 같은 2장**이 나오고, 문구도 「관련 해봤노트가 2개 있어요」다. `oneLine`도 비어 있다. 토익 스터디(없는 프로그램)에도 이 2장이 나와 「있는 것처럼」 보인다.

## Q-50에 줄 수선 제안

1. **프로그램 이름 대조를 넓힌다**(T1, 10건): 130개 이름에서 `[ ]`·`( )`·「프로그램」「수료자」 같은 군더더기를 뺀 핵심 이름과 영문 약칭(GAT·BYOI)을 `programs.json` 별칭으로 더하거나(원우 데이터), `match_programs`에 핵심어 부분 일치를 둔다. 단 유형어(튜터링·멘토링·특강)는 프로그램 하나로 잡지 않는다.
2. **근거 0인 비교과는 「없다」 대신 코드가 가진 사실로 답한다**(T5·T4, 7건): 이수 인원·만족도·세부 유형·운영부서(AI 없음)를 안내하고 「경험담은 아직 없어요」를 덧붙인다. 만족도·인원 질문(23)은 `rank`처럼 코드가 세어 답한다.
3. **비교과 탐색은 근거 있는 2개만 보여 주지 않는다**(T2·T3, 7건): 유형·세부 단위 질문은 그 세부(`세부`)의 프로그램 목록(130개 풀)에서 카드를 고르고, 이름·세부가 하나도 안 맞으면(토익 스터디) 「없는 프로그램」으로 보류한다. 늘 같은 2장이 나오는 길(`_explore`의 `evidence_count(n)` 필터)을 비교과에서는 풀어야 한다.

참고: 비교과 근거 문장 자체가 없는 것은 코드로 풀 수 없다(데이터). 원우 데이터 쪽 결정 필요 — 비교과 후기 문장을 만들 것인지, 이수 통계 안내로 갈 것인지.

## 원우 측정 세트와의 겹침

`data/eval-questions.csv`의 비교과 질문은 26(BUDDY)·27(직무탐색)·28(Jump Start)·50(컬처핏) 4개이며 모두 기대 결과가 보류다. 이 조사의 1번(직무탐색 교육)은 27번과 같은 프로그램을 다른 말로 물은 것이고, 나머지는 겹치지 않는다. 원우 세트의 26~28·50은 「정식 이름·근거 없음 → 보류」만 보므로, 이름 불일치(T1)·유형 단위(T2)·카드 2장(T4) 같은 이 조사의 유형은 세트에 없다.

## Q-50 수선 뒤 (11/26 미리, 작업 106 — 로컬 AI 없음 경로)

같은 27문을 로컬에서 `askBoo`(질문정리 실패 v1 길 + 질문정리가 「분야: 비교과」로 정리했다고 둔 길, 답쓰기 호출 0)로 다시 돌렸다. 두 길 결과가 같다(유형·순위·비교는 질문정리 앞에서 코드가 답함).
