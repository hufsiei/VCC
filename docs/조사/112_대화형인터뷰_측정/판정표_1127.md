### 6-3. 걸린 턴 (원문)

#### G01 · 「저 3학년이에요」 (2/2) — 코드 바로잡기가 원인
- 방금 질문: [활동내용] 교육혁신원 대동제 이벤트 Guardians에서는 어떤 활동을 했어요?
- 기대: 딴얘기·부족, 같은 칸 다시 묻기
- 말판정 원문: `{"종류": "부족", "궁금": null}` (2회 같음, 기대 맞음)
- 코드 뒤: **답** — `fix_kind`의 「부족·딴얘기인데 숫자가 든 말 → 답」
- 반응: 「3학년이시군요.」 · 다음: [배운점]으로 넘어감
- 차이: 학년 말이 [활동내용]의 답으로 세어져 요약 입력에 들어간다.
- 2회차 폴백 「질문 버림」: 대화쓰기 질문 「Guardians에서는 어떤 활동을 했는지 편하게 들려주세요. 맡은 역할도 좋아요.」의 뒤 문장을 코드가 떼어 낸 것이 폴백으로 세어졌다(앞 문장은 화면에 나감).
- 미리 판정:

#### G03 · 「2번 질문 다시 보여 줘요」 (2/2)
- 방금 질문: [팁] 후배들이 마르부르크에 대해 잘 모르고 있는 것, 또는 잘못 알고 있는 게 있다면요?
- 기대: 되물음·딴얘기, 안 담음
- 말판정 원문: `{"종류": "되물음", "궁금": "2번 질문 다시 보여 줘요"}`
- 결과: 되물음(맞음), **내 질문함에 「2번 질문 다시 보여 줘요」가 담김**
- 반응: 「궁금하신 점은 내 질문함에 담아 두었어요.」 · 다음: 팁을 다른 말로 다시 물음
- 미리 판정:

#### G13 · 「제가 적은 거 후배한테 이름도 같이 보이나요?」 (2/2)
- 기대: 되물음, 안 담음
- 말판정 원문: `{"종류": "되물음", "궁금": "제가 적은 거 후배한테 이름도 같이 보이나요?"}`
- 결과: 되물음(맞음), **내 질문함에 담김**
- 반응: 「궁금하신 점은 내 질문함에 담아 두었어요.」
- 대화쓰기는 「그건 제가 알 수 없어요. 공개할 문장은 선배가 직접 고르게 돼요.」를 썼지만 담은 턴은 코드가 반응을 지운다(`NO_REACTION_HELD`). 선배는 이름 공개 여부에 대한 답을 못 받는다.
- 미리 판정:

#### G14 · 「이거 중간에 나갔다가 이어서 해도 저장돼요?」 (2/2)
- 기대: 되물음, 안 담음, 같은 칸 다시 묻기
- 말판정 원문: `{"종류": "딴얘기", "궁금": null}`
- 결과: **딴얘기**, 안 담음(맞음), 다시 물음(맞음)
- 반응: 「그건 제가 알 수 없어요.」
- 차이: 딴얘기와 되물음은 둘 다 같은 질문을 다시 묻는 길이라, 이 턴에서 화면 흐름은 기대와 같았다. 종류 이름만 다르다.

### 6-4. 기준 밖에서 본 것
