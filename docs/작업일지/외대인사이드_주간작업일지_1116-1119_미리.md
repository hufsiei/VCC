- HCX는 11/19 askBoo 채점·54·53 측정으로 573건을 호출했습니다(성공 569, 429 등 실패 4. 기록: `functions/logs/ai-calls.jsonl`, 저장소 제외). 54의 한도 확인용 연속 호출 15건은 이 기록에 들어가지 않습니다. Claude는 키를 넣었지만 **Anthropic 크레딧 부족으로 아직 한 건도 성공하지 못했습니다.** 요약·일치 검사를 Claude로 쓰기로 했으므로 작업 21 전에 충전이 필요합니다.
- 서버 함수는 쓰기 8개 + askBoo입니다. `login`·`getNote` 등이 없어 브라우저 두 창 시연은 아직 확인하지 못했습니다.
- askBoo의 질문 주제어 사전(`TOPICS_EXCHANGE`)은 개발 질문 53개를 보며 만들었습니다. 봉인 30개로 다시 확인해야 실제 성능을 알 수 있습니다.
- 마스킹(`mask.py`)이 아직 없어 지금 `callAI`는 입력을 가리지 않고 보냅니다. 시연 데이터는 가상이지만, 작업 72를 마칠 때까지 실제 개인정보를 넣어 시험하지 않습니다.
- 작업 47·53은 기한(11/19)을 넘깁니다. 47은 크레딧, 53은 Claude 크레딧에 막혀 있습니다.
- 팀 가이드 v2 상단 일정은 v5 기준(12/5 온라인 리허설)이라 v6 일정과 다릅니다. 일정은 작업내역 v6을 따릅니다.
