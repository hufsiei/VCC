## 2. 장면 (4분) — 질문은 아래 문장 그대로 입력

> ⚠ 지금 화면은 **mock**이라 질문 내용과 상관없이 정해진 답 3가지(답변·보류·공식안내)만 나온다.
> 학생이 직접 다른 질문을 입력하면 엉뚱한 답이 나오므로, **입력은 진행자가 하거나 아래 문장을 그대로 쓰게** 한다.
> 학생이 물어보고 싶은 질문이 있으면 화면에 넣지 말고 **기록표에 받아 적는다**(실제 수요 자료).

| # | 시간 | 장면 | 입력·누를 것 | 화면에서 보여 줄 것(11/23 확인) | 물어볼 것 |
|---|---|---|---|---|---|
| ① | 1분 | 인터BOO 물어보기 — 근거 있는 답 | 「마르부르크 파견 가려면 언제부터 준비해요?」 입력 → 근거 줄의 「펼치기」 | 답 3문장(TestDaF 3학기 전·기숙사 합격 직후·첫 학기 적응) + 「근거 3건 · 결과보고서 2 · 선배 인터뷰 1」 | 「이런 답이면 믿고 쓰겠어요? 출처 표시는 도움이 되나요?」 |
| ② | 40초 | 근거가 없을 때 — 지어내지 않음 | 「현지에서 아르바이트 할 수 있어요?」 입력 | 「아직 들은 선배가 없어요. 질문함에 담아 두었어요」 + 「근거 0건」 틀 유지 (「닮은선배 보기」는 0번 확인 결과대로) | 「답을 못 할 땐 이렇게 '모른다'고 하는 게 낫나요, 아쉬운가요?」 |
| ③ | 1분 30초 | 해봤노트 — 선배 경험 모음 | ①의 답 아래 「마르부르크필립스대학교 해봤노트 보기 ›」 → 칸 탭을 **지원 → 비용 → 후배 질문** 순서로 | 지원: 문장 2개 + 「선배 2명의 경험이에요」 / 비용: 「근거 0건」 + **「질문함에 담기」** 버튼 / 후배 질문: Q·A 한 쌍(학기 중 인턴 병행) | 「교환·인턴 정보를 지금은 어디서 찾나요? 이게 있으면 쓰겠어요?」 |
| ④ | 30초 | (시간 남으면) 규정 질문 | ← 뒤로 → 인터BOO에 「학점 인정 신청은 언제까지예요?」 입력 | 「국제교류팀 공식 안내에서 확인해 주세요」 + 「공식 안내 보기 ›」 | 「규정은 공식 안내로 넘기는 게 맞을까요?」 |

마지막 질문(30초): **「한 줄로 말하면 — '맞아, 그거 불편했어' / '이건 안 쓸 것 같아' 중 어느 쪽이에요? 이유는요?」**

보여 주지 않는 것(학생 역할과 맞지 않거나 아직 준비 중):
- 「들려주기」 탭: 경험이 있는 선배용 화면이다. 학생이 교환·인턴 경험자라면 마지막에 「경험이 있으면 이렇게 들려줄 수 있어요」 정도로 화면만 보여 준다(입력은 하지 않음).
- 「내 보관함」: mock 고정값(경험노트 1개, 「노트 틀 4/7」)이라 후배 입장과 맞지 않는다.
- 「궁금한 것 정리하기」(선배 추천 열림, 11/22 추가): 공개 주소 화면에는 아직 없다.
