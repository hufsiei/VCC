## 막힌 점·배운 점
- **사전은 '잡아야 할 질문'만이 아니라 '잡으면 안 되는 질문'으로도 시험해야 함.** 직군 질문 14개는 첫 판부터 다 맞았지만, 인턴과 관계없는 질문 30개를 넣어 보니 28개가 걸렸음(교환 여행 → 여행사 인턴, 행정실 연락처 → 공공기관 인턴). 문맥 말 조건을 넣어 0건으로 줄임
- **짧은 키워드가 긴 말 안에 숨어 있을 수 있음.** '여행사' 안의 '행사' 때문에 여행사 질문에 KOTRA 전시·행사가 걸림 → 별칭과 같은 긴 키워드 우선 규칙
- **새 규칙은 기존 규칙과의 순서까지 시험해야 함.** 지역번호 없는 번호 규칙을 해외 번호 규칙 앞에 두니 해외 번호가 반만 가려짐. 기존 시험 묶음(12,383건)을 그대로 다시 돌려서 찾음
- **유형 이름만 보고 지표를 세면 틀림.** '함정'이라도 기대결과가 답변인 질문이 있음(개발 35)
- **받는 쪽 코드를 먼저 읽어야 함.** spec과 실제 askBoo 코드가 기대하는 파일 모양이 달랐음 → spec 모양으로 만들고, 기존 코드에선 아무 영향이 없도록 함
- AI 키는 팀원에게 나누지 않는 규칙이라, 측정은 누가 어디서 돌릴지 미리 정해야 함
