## 2. 장면 (4분) — 질문은 아래 문장 그대로 입력

> ⚠ 지금 화면은 **mock**이라 질문 내용과 상관없이 정해진 답 몇 가지(답변·보류·공식안내·노트 안내)만 나온다. 교환·마르부르크가 들어간 질문은 모두 **생활비 답**이 나온다(11/25 확인 — 「교환학생 언제부터 준비해요?」를 넣어도 생활비 답). 「안녕」에도 보류 답이 나온다.
> 학생이 직접 다른 질문을 입력하면 엉뚱한 답이 나오므로, **입력은 진행자가 하거나 아래 문장을 그대로 쓰게** 한다.
> 학생이 물어보고 싶은 질문이 있으면 화면에 넣지 말고 **기록표에 받아 적는다**(실제 수요 자료).

| # | 시간 | 장면 | 입력·누를 것 | 화면에서 보여 줄 것(11/25 확인) | 물어볼 것 |
|---|---|---|---|---|---|
| ① | 1분 | 인터BOO 물어보기 — 근거 있는 답 | 「**마르부르크 가면 한 달 생활비 얼마나 들어요?**」 입력 → 근거 줄의 「펼치기」 | 답 3문장(월 125만 원쯤·월세 포함 110만 원·넉넉히 140만 원) + 「근거 3건 · 결과보고서 3」(발표 시연 첫 장면과 같은 질문) | 「이런 답이면 믿고 쓰겠어요? 출처 표시는 도움이 되나요?」 |
| ② | 1분 | 근거가 없을 때 → 닮은선배 | 「현지에서 아르바이트 할 수 있어요?」 입력 → 「닮은선배 보기」 → 선배 A 「프로필 보기」 → 뒤로 → 선배 A 「쪽지 보기」 | 「아직 경험한 선배가 없어요. 질문함에 담아 두었어요」 + 「근거 0건」 / 추천 선배 2명, 추천 이유 5개, 「이름과 학번은 보이지 않아요」 / 쪽지(선배에게는 별명으로 보임). 선배 B 「쪽지 요청」은 날짜 잠김이라 누르지 않는다 | 「답을 못 할 땐 이렇게 '모른다'고 하는 게 낫나요? 이런 선배라면 쪽지를 보내 보겠어요?」 |
| ③ | 1분 30초 | 해봤노트 — 선배 경험 모음 | 아래 「인터BOO」 탭 → ①의 답 아래 「마르부르크필립스대학교 해봤노트 보기 ›」 → 칸 탭을 **지원 → 비용 → 생활** 순서로 | 지원: 문장 2개 + 「선배 2명의 경험이에요」 / 비용: 요약 문단(월 110만~140만 원, ①의 답과 같은 근거) + 「원문 3건 보기」 / 생활: 요약 문단 + 「새로 더해진 선배 이야기 2건」(선배 인터뷰) | 「교환·인턴 정보를 지금은 어디서 찾나요? 이게 있으면 쓰겠어요?」 |
| ④ | 30초 | (시간 남으면) 규정 질문 | ← 뒤로 → 인터BOO에 「학점 인정 신청은 언제까지예요?」 입력 | 「국제교류팀 공식 안내에서 확인해 주세요」 + 「공식 안내 보기 ›」 | 「규정은 공식 안내로 넘기는 게 맞을까요?」 |

마지막 질문(30초): **「한 줄로 말하면 — '맞아, 그거 불편했어' / '이건 안 쓸 것 같아' 중 어느 쪽이에요? 이유는요?」**

보여 주지 않는 것(학생 역할과 맞지 않거나 아직 준비 중):
- 「들려주기」 탭: 경험이 있는 선배용 화면이다. 학생이 교환·인턴 경험자라면 마지막에 「경험이 있으면 이렇게 들려줄 수 있어요」 정도로 화면만 보여 준다(입력은 하지 않음).
- 「내 보관함」: mock 고정값(경험노트 1개, 「노트 틀 3/6」)이라 후배 입장과 맞지 않는다.
- 「궁금한 것 정리하기」(선배 추천 열림): mock에서는 추천이 이미 열려 있어 닮은선배에 보이지 않는다.
- 해봤노트 목록: mock은 노트가 3개뿐이고 비교과 노트는 「근거 0건」이다. 학생이 다른 노트를 찾으면 실제 앱에는 더 많다고 말로만 설명한다.
- 「○○ 교환 다녀온 선배 있어요?」 같은 **사람 찾기 질문**: 나라와 상관없는 노트가 나온다(11/25 확인 — 네덜란드를 물어도 마르부르크 노트). 학생이 물어보려 하면 기록표에만 적는다.
