## 막힌 점·배운 점
- **짧고 깔끔한 시험 문장만으로는 정규식 오류를 못 찾음.** 다시 검증할 때 '붙여 쓴 문장', '긴 글', '근거 문단에 끼워 넣기'로 시험하니 mask.py의 속도 폭주(5만 자 40초)와 쪽지 금지어 오탐('3시 발표'가 '시발표'로 걸림)을 찾음
- **단톡 문구를 줄일 때 서로 다른 사람의 사실을 한 문장에 묶으면 헷갈림.** 닮은 선배 공유에서 1위의 공통 비교과가 2위 것으로 읽힘 → 대상마다 줄을 나눠 씀
- 원본 엑셀이 `data/`의 원본이라 csv만 고치면 다음 변환 때 되돌아감 → 엑셀을 고치고 드라이브에 다시 올림
- PR 본문에 md 파일을 끌어 놓으면 첨부 링크로만 들어감 → 내용을 복사해 붙여 넣어야 함
- 열린 PR에 푸시하면 커밋은 자동으로 들어가지만 제목·본문은 직접 고쳐야 함
- 로컬 '공유' 폴더는 팀원이 볼 수 없음 → 단톡 첨부나 드라이브로 공유
