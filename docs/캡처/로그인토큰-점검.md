# 로그인 토큰 수동 점검 (PRD 9-4 점검표 6번, 작업 73·86)

2026-11-20, `python functions/local_fn.py`(시험용 `VCC_LOGIN_PW`)에 curl. 토큰 값은 가렸다.

| # | 요청 | 결과 |
|---|---|---|
| ① | `POST /getInbox` 토큰 없음 | `{"error": "로그인이 필요해요"}` |
| ② | `POST /getInbox` + `X-User: H0143` | `{"error": "로그인이 필요해요"}` |
| ③ | H0143 토큰으로 남의 쪽지 `POST /respondRequest {"threadId":"T-9999"}` | `{"error": "볼 수 없는 기록이에요"}` |
