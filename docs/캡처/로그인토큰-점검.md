# 로그인 토큰 수동 점검 (PRD 9-4 점검표 6번, 작업 73·86)

2026-11-20, `python functions/local_fn.py`(시험용 `VCC_LOGIN_PW`)에 curl. 토큰 값은 가렸다.

| # | 요청 | 결과 |
|---|---|---|
| ① | `POST /getInbox` 토큰 없음 | `{"error": "로그인이 필요해요"}` |
| ② | `POST /getInbox` + `X-User: H0143` | `{"error": "로그인이 필요해요"}` |
| ③ | H0143 토큰으로 남의 쪽지 `POST /respondRequest {"threadId":"T-9999"}` | `{"error": "이 요청에 답할 수 없어요"}` — **브리프의 `볼 수 없는 기록이에요`와 다름**(아래 참고) |
| ④ | H0143·H0469 각각 로그인, 두 토큰으로 `getMe` / H0143 재로그인 뒤 첫 토큰으로 `getMe` | 각자 자기 `colreg_no`로 응답, 재로그인해도 이전 토큰 유지 |
| 추가 | 틀린 비번(`1`) 로그인 | `{"ok": false, "reason": "아이디 또는 비밀번호가 맞지 않아요."}` |
| 추가 | `logout` 뒤 같은 토큰으로 `getMe` | `{"error": "로그인이 필요해요"}` |
